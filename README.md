A modern, fast, and responsive **CGPA & GPA Calculator** custom-built for **Uttara University** students. Easily calculate semester GPAs, track cumulative CGPA across 12 semesters (Day Shift) or 10 semesters (Evening Shift), import ERP results, and generate printable academic transcripts with a single click.

## ✨ Features

- 📊 **Dual Shift Support**: Switch seamlessly between **Day Shift (12 Semesters)** and **Evening Shift (10 Semesters)**.
- 🔐 **Student ERP Integration**: Log in with your Student ID and ERP Credentials for quick authentication and session sync.
- ⚡ **1-Click Demo Login**: Explore the full suite instantly without entering credentials.
- 🎯 **Target CGPA Predictor**: Calculate the exact required GPA needed in upcoming semesters to hit your target CGPA.
- 🖨️ **Printable Academic Summary**: Generate clean, printable PDF transcripts with custom course entries.
- 📱 **Fully Responsive UI**: Mobile-optimized design with a native bottom navigation bar and slide-up drawer menus.
- 💾 **Local Data Persistence**: Saves your courses, grades, and shift selections locally inside your browser (`localStorage`).
- 🔍 **SEO & Accessibility Optimized**: Built with semantic HTML5, Schema.org JSON-LD structured data, and OpenGraph tags.

| Marks Range | Letter Grade | Grade Point | Performance |

## 💻 Local Setup & Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/sabbirhussankhan/CGPA-CALCULATOR.git
   ```

2. **Navigate into Directory**:
   ```bash
   cd CGPA-CALCULATOR
   ```

3. **Open in Browser**:
   Double-click `index.html` or run with Live Server in VS Code / Antigravity IDE.
